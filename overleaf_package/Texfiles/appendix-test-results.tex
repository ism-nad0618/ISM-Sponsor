\subsection{Known Issues and Limitations}

\subsubsection{Azure Coverage Preview Endpoint (AZURE-07)}

\textbf{Issue:} The coverage evaluation endpoint returns HTTP 500 error on Azure production environment while functioning correctly in local development.

\textbf{Error Response:}
\begin{verbatim}
{
  "error": "An error occurred processing your preview request",
  "requestId": "40001631-0004-ef00-b63f-84710c7967bb"
}
\end{verbatim}

\textbf{Root Cause:} Missing seed data in Azure SQL Database. The Items, ItemCategories, and Students tables lack test data required for coverage evaluation logic.

\textbf{Impact:} LOW - Does not affect pilot demonstration. Local environment provides full functionality for coverage evaluation demonstrations.

\textbf{Workaround:} Use local development environment (\url{http://localhost:5000}) for coverage evaluation demonstrations during pilot phase.

\textbf{Remediation Plan:} Execute comprehensive database seeding scripts on Azure SQL Database before production deployment. Verify presence of Items, ItemCategories, and Students reference data.

\subsubsection{Integration Sync Status (API-I-01)}

\textbf{Issue:} The /api/v1/integrations/sync-status endpoint returns empty response.

\textbf{Root Cause:} External system integration (PowerSchool, NetSuite, OBS) was not configured for pilot demonstration.

\textbf{Impact:} LOW - This is by design for pilot phase. Full integration is deferred to production deployment phase.

\textbf{Status:} Working as designed for demo mode.
